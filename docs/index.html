formulit — 手書き HTML を欠落させない WYSIWYG エディタ

Lit で使えるリッチテキストエディタ（<formulit-editor>）です。class・style・data-*・独自要素・コメント・iframe などを保持し、編集していない部分は元の文字列のまま返します。CKEditor 5 のオープンソース機能をおおむね備え、ビルド不要の ES モジュールで動きます。

はじめる → プレイグラウンドで試す HTML 保持の仕組み

npm install @hidemikimura/formulit lit

ライブデモ

手書きの HTML を読み込んだエディタです。下の「value」に、エディタが返す HTML がそのまま表示されます。一部を編集しても、触っていない部分の書き方（シングルクォート・大文字タグ・&copy;・コメントなど）は変わりません。

ライブデモ未編集：読み込んだ文字列をそのまま返しています

    

  

  

  
特長

  

    
🧩
手書き HTML を保持
モデルに変換せず DOM をそのまま編集。未編集なら 1 文字も変えず、編集後も触っていない部分は原文のまま返します。

    
⚡
Lit ネイティブ
カスタム要素なので Lit のテンプレートに .value と @input で組み込めます。フォームにもそのまま入ります。

    
🧰
CKEditor 相当の機能
書式・画像・表（結合・分割）・メディア埋め込み・コードブロック・検索置換・自動保存・目次・差し込み変数など。

    
🎛️
ツールバーを自由に構成
項目の並びに加えて、{ label, items } でドロップダウンにまとめられます。アイコンも指定可能。

    
🔌
プラグインで拡張
組み込み機能もすべてプラグイン。ボタン・セレクト・ドロップダウン・ショートカットを数行で追加できます。

    
🇯🇵
日本語入力に対応
IME の変換中はショートカットを無視し、確定した文字にも書式を適用。Chrome・Firefox・Safari で検証済み。
