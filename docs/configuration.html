設定

属性（HTML に書く）と、JS プロパティ（配列や関数）で設定します。

設定を試す

ライブデモチェックを切り替えると、エディタにそのまま反映されます

  






属性


属性で書けるものは、同名（キャメルケース）のプロパティでも設定できます。



  
属性プロパティ既定値説明

  
name—フォーム送信時の名前

  
valuevalueHTML。属性は初期値のみ（ブラウザが整形）。プロパティに設定した文字列は 1 文字も変えずに保持

  
placeholderplaceholder''空のときの表示

  
readonlyreadonlyfalse読み取り専用

  
toolbartoolbarDEFAULT_TOOLBAR項目名を空白区切り。グループはプロパティ（配列）で → ツールバー

  
pluginspluginsすべて有効にするプラグイン名（空白区切り）

  
sanitizesanitize'strip'strip: script / on* / javascript: を除去。none: 残す（編集中だけ無効化）

  
protectprotectDEFAULT_PROTECT編集中に丸ごと保護する要素の CSS セレクタ

  
preserve-sourcepreserveSourcetrue編集後も未変更部分を原文のまま返す。無効は "false"

  
autoformatautoformattrueMarkdown 風の入力変換。無効は "false"

  
word-countwordCountfalseステータスバーに文字数・単語数

  
max-charsmaxChars0文字数の上限表示（超えると赤字。入力は止めない）

  
autosave-delayautosaveDelay2000自動保存までの待ち時間（ms）

  
fullscreenfullscreenfalse全画面表示





JS プロパティ（配列・関数）



  
プロパティ形式説明

  
fontFamilies / fontSizes / lineHeights[{ value, label }]フォント・文字サイズ・行間の選択肢（value: '' は「指定なし」）

  
colors[{ color, label }]文字色・背景色のパレット

  
formatStyles[{ name, element, classes }]「スタイル」で選べるクラス。未設定ならボタン非表示

  
imageUploaderasync (file) => url画像のアップロード先。未設定なら data URL

  
imageStyles[{ name, label, style?, classes? }]画像の配置（inline / alignLeft / alignCenter / alignRight）

  
codeBlockLanguages[{ value, label }]コードブロックの言語

  
mediaProviders[{ name, re, src, width, height }]埋め込みに対応する URL

  
autosaveasync (html, editor) => {}自動保存

  
slashCommands配列 / falseスラッシュコマンドの一覧（false で無効）

  
variables[{ type: 'group', label, variables: [{ label, value }] }]挿入できる変数（変数の挿入）。未設定なら「変数」ボタン非表示

  
variableFormat{ open, close } / (variable) => string挿入する文字列の書式（既定 {{ value }}）

  
variableTriggerstring / false本文で変数の候補を出す文字列（既定は variableFormat.open）





書式の選択肢を変える


フォント・サイズ・色・「スタイル」の選択肢はプロパティで差し替えます。「スタイル」に登録したクラスの見た目は、ページの CSS で定義します（エディタの中にも同じ CSS が効きます）。

見た目の調整


エディタの枠・ツールバーは CSS 変数と ::part() で、本文の見た目はページの CSS で調整します（編集領域はシャドウ DOM の外にあるので、サイトの本文用 CSS がそのまま効きます）。



  
CSS 変数既定値

  
--formulit-min-height240px

  
--formulit-padding12px 16px

  
--formulit-border#d0d4d9

  
--formulit-radius6px

  
--formulit-bg / --formulit-toolbar-bg#fff / #f7f8fa

  
--formulit-fullscreen-width860px（全画面時の本文幅）




::part(): toolbar、body、source（HTML ソースの textarea）、status（ステータスバー）
