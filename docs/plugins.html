プラグインの作り方

組み込み機能もすべてプラグインとして実装されています。registerPlugin() で登録し、項目名を toolbar に書くと表示されます。

ライブデモ

下のエディタには、このページのコード（すぐ下に表示）で作った 5 つの独自プラグインが入っています: マーカー（ボタン・ショートカット）、字間（セレクト）、定型文（ドロップダウン）、注意ボックス（コンテキストツールバー）、段落数（ステータスバー）。

ライブデモ注意ボックスの中にカーソルを置くと、専用のツールバーが出ます

登録のタイミング: registerPlugin() はエディタ要素が DOM に追加される前に呼ぶのが基本です。ツールバー項目は後からでも反映されますが、init() は接続時、prepare() は内容の読み込み時に登録済みのプラグインにだけ適用されます。

キー説明
type'button'（既定）/ 'select' / 'dropdown'

action(ed, value)クリック時（select は選んだ値）

active などはツールバーを描画するたびに呼ばれます。文書全体の走査など重い処理はしないでください。

内容を変更する

DOM の変更は必ず ed.transact(() => { … }) の中で行います。1 回の「元に戻す」単位になり、input イベント・フォームの値・原文保持の変更検知が正しく働きます。

API用途
ed.exec(command, value)execCommand を 1 回実行
ed.insertNodes(node) / ed.insertNodesAtSelection(node)ノードを挿入（transact 外 / 内から）。ブロックは段落を分割して入る
ed.insertHTML(html)HTML 文字列を挿入（サニタイズされる）
ed.applyInline(ops)[{ kind: 'style', prop, value }] / [{ kind: 'wrap', tag, classes, remove? }]。範囲なしなら次に入力する文字に適用
ed.toggleInline({ tag, classes }) / ed.isInlineActive(…)要素で囲む書式の切り替え / 状態
ed.setBlockStyle(prop, value)選択中の段落などに style（空で解除）
ed.closestAtSelection(selector) / ed.selectedBlocks() / ed.getRange()カーソル位置の要素・ブロック・範囲

ショートカット

キーは Mod（Mac は ⌘、それ以外は Ctrl）・Alt・Shift と event.key（1 文字は小文字）を - でつなぎます: 'Mod-b'、'Mod-Shift-z'、'Alt-0'、'Enter'、'Tab'、'Escape'。

値が関数のとき false を返すと「処理しなかった」扱いになり、次のプラグインやブラウザ既定の動作に回ります。Enter や Tab のような条件付きのキーは、該当しないとき必ず false を返してください。日本語入力の変換中のキーは自動で除外されます。

ダイアログ

type: text / url / number / checkbox / select（options）/ textarea / color / file。閉じると開く前の選択位置に戻ります。

読み込み時の調整（prepare と setTemp）

編集中だけ属性を変えたいときは、prepare の中で setTemp(el, name, value) を使います。書き出し時に値と属性の並び順が元に戻ります。data-formulit- で始まる属性は内部用として出力から自動的に除かれます。

やってはいけないこと

  • ed.editable.innerHTML = … で書き換える（ed.value = … を使う）
  • transact の外で DOM を変える
  • active などで文書全体を毎回走査する
  • _ で始まる内部メソッドに依存する（_withoutFocus を除く）
