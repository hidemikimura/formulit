ツールバー

並べる項目を配列で指定します。{ label, items } を書くと、その項目を 1 つのドロップダウンにまとめられます。

指定方法

editor.toolbar に配列を渡します（未指定なら DEFAULT_TOOLBAR）。要素は「項目名」「'|'（区切り線）」「グループ」のいずれかです。

グループを使わないなら属性でも書けます: <formulit-editor toolbar="bold italic | link">

グループ

キー説明
items中に入れる項目名の配列。'|' で区切り線。フォントなどのセレクトや、文字色などのドロップダウンも入れられます（パネルの中で入れ子に開きます）
labelボタンに表示する文字
iconボタンのアイコン。項目名（'bold' → 太字のアイコン）、HTML 文字列、Lit の html / svg テンプレート。label と併用できます
titleツールチップ（省略時は label）
keepOpentrue なら、中の項目を実行してもパネルを閉じません（既定は閉じる）
nameグループの識別名（任意）
  • label と icon をどちらも省略すると ⋯ と表示します。
  • 中のどれかが押下状態（太字の中にカーソルがあるなど）のときは、グループのボタンも押下表示になります。
  • Ctrl/⌘+F などのショートカットでグループの中のパネルを開く場合は、グループごと開きます。

icon に渡した HTML 文字列はそのまま描画されます。開発者が書いた固定の値だけを渡し、利用者の入力など信頼できない値は渡さないでください。

機能を絞る

  • ボタンを減らすだけなら toolbar から外します。ショートカットや入力変換は残ります（bold を外しても Ctrl+B は効く）。
  • 機能ごと無効にするなら plugins で有効なプラグインを列挙します（例: plugins="core basic link"）。組み込みプラグイン: core basic formatting typing codeBlock lists link image embed productivity table
  • 入力変換だけ止めるなら autoformat="false"、スラッシュコマンドは editor.slashCommands = false。
