機能一覧

CKEditor 5 のオープンソース機能をおおむね備えています。各デモで実際に操作できます。

分類機能

入力補助書式のコピー、大文字・小文字の変換（Shift+F3）、特殊文字・絵文字、書式をクリア

文字色・サイズなどは <span style="…"> で出力します（<font> や 7 段階のサイズは使いません）。範囲を選ばずに指定すると、次に入力する文字（日本語入力の確定文字を含む）に適用されます。

ライブデモ文字を選んで書式を付けてみてください

画像

  • 挿入・編集（URL・代替テキスト・サイズ）。ファイルは選択・ドラッグ＆ドロップ・貼り付けでアップロード（imageUploader 未設定なら data URL で埋め込み）。
  • 画像をクリックすると専用ツールバー: 配置（文中・左・中央・右）、キャプション、設定、リンク、削除。四隅のハンドルでリサイズ。
ライブデモ画像をクリックしてみてください（この例のアップロードは data URL）

表

  • 行・列の挿入（上下左右）と削除、セルの結合・分割、見出し行・見出し列、キャプション、表とセルのプロパティ（枠線・背景・幅・配置）。
  • 結合セル（rowspan / colspan）をまたぐ操作でも表の形が崩れないように処理します。Tab で次のセルへ（最後のセルでは行を追加）。
ライブデモセルをドラッグで複数選び、表のツールバーの「結合」を押してみてください

埋め込み・コード

  • メディア: YouTube・Vimeo・Dailymotion・Spotify・Google マップの URL を iframe で埋め込み。URL を貼り付けるだけでも埋め込まれます。
  • HTML 埋め込み: HTML の断片をそのまま挿入し、ダブルクリックで編集。
  • コードブロック: 言語を指定（<code class="language-js">）。Enter で改行、末尾で 3 回押すと抜ける、Tab でインデント、貼り付けはプレーンテキスト。
ライブデモコードブロック内で Enter や Tab を押してみてください。ボタンのような要素はダブルクリックで HTML を編集できます

変数の挿入

メールテンプレートや帳票の文面に、差し込み用の変数（{{ product_name }} など）を入れるための機能です。variables を設定すると使えるようになります。

  • ツールバーの「変数」: 検索欄つきのコンボボックスが開きます。文字を入力して絞り込み、↑↓ と Enter、またはクリックで挿入します。
  • 本文で {{ と入力: キャレットの位置に同じ候補が出ます。続けて入力すると絞り込み、Enter / Tab で {{〜入力した文字を変数に置き換えます。Esc で閉じると、{{ はそのまま残ります。全角の ｛｛ でも開きます。
  • 絞り込みの対象はグループ名・変数名・変数値。空白で区切ると AND 検索になり、大文字小文字・全角半角・ひらがなとカタカナは区別しません（「こーど」で「SKUコード」に一致）。
  • 挿入されるのはただの文字列です。出力 HTML に特別な要素や属性は入りません。
ライブデモ「変数▼」を押すか、本文で {{ と入力してみてください
