インストールと基本

formulit を読み込んで <formulit-editor> を置くまでと、値の受け渡しの基本です。

インストール

lit 3 が必要です（peerDependency）。ビルド不要の ES モジュールなので、Vite などのバンドラーでも、ビルドなしの import map でも使えます。

ビルドなし（import map）で使う

lit 一式（lit / lit-html / lit-element / @lit/reactive-element）を import map で解決します。lit@3/+esm の 1 ファイルだけにすると、formulit が使う lit/directives/… が別のコピーになるので避けてください。

最小の例

import '@hidemikimura/formulit' で <formulit-editor> が定義され、組み込みの機能（プラグイン）がすべて登録されます。

Lit のコンポーネントから使う

.value=${this.body} は値が変わるたびにエディタへ設定されます。@input で受け取った値をそのまま戻す分には、同じ文字列なので再設定されません。外から別の文字列を入れると「新しい原文」として読み込み直し、元に戻す履歴はリセットされます。

初期値の渡し方

方法原文の保持
子に <script type="text/html">…</script>1 文字も変えずに読み込みます（中で </script> を書くときは <\/script>）
value プロパティに文字列を設定1 文字も変えずに読み込みます（サーバーから受け取った HTML、Lit の .value=${…} など）。ページに付ける前に設定してもよく、その場合は子要素の初期値より優先します
子に <template>…</template> / value 属性ブラウザが先にパースするため、引用符・大文字・文字参照の書き方は整形されます（内容は保持）

値の取得と変更の検知

  • editor.value（または getHTML()）で HTML を取得、代入（または setHTML(html)）で設定します。
  • input イベント: 内容が変わるたび（入力・書式変更・元に戻す など）。event.target は <formulit-editor> です。
  • change イベント: フォーカスが外れたとき、内容が変わっていれば。
  • editor.dirty: 読み込んでから編集されたか。
ライブデモ入力するとイベントの回数と value が更新されます

input: 0 回 ／ change: 0 回 ／ dirty: false


  






input のたびに大きな DOM へ value を描画する処理は重くなります。表示の更新は 150ms 程度間引くのがおすすめです。



フォームで送信する
