Markdown エディタ（formulit-markdown）

<formulit-markdown> は、Typora のように見たまま編集して、Markdown（GFM）で保存するエディタです。formulit のツールバー・プラグイン・入力補助をそのまま使い、value だけが Markdown になります。

ライブデモ

value（Markdown）


    

  






特長


    
  
  • 編集していない部分は原文のまま：未編集なら読み込んだ Markdown を 1 文字も変えずに返します。編集後も、触っていないブロック（段落・リスト・表など）は原文の書き方（* と -、__ と **、setext 見出し、参照リンク、空行の数）を保ち、編集したブロックだけを書き直します。上のデモで一部だけ編集して確かめてください。
    • 
  
  • GFM：表（配置つき）・取り消し線・ToDo リスト（クリックで完了）・URL の自動リンク。
    • 
  
  • 表せない内容は HTML のまま：文字色・下線・結合セル・属性付きの要素・独自要素などは、Markdown の中に HTML として残ります（GitHub などでもそのまま表示されます）。
    • 
  
  • 貼り付けとコピー：Markdown の文字を貼り付けると書式付きで入り、コピーした文字（text/plain）は Markdown になります。
    • 
  
  • ソース表示は Markdown：ツールバーの「</>」で Markdown を直接編集できます。
    • 
  
  • 元に戻す・検索と置換・文字数・自動保存・全画面・差し込み変数・フォーム連携など、formulit の機能はそのまま使えます。
    • 




インストールと使い方



@hidemikimura/formulit と lit 3 は peerDependency です。Markdown の解析には markdown-it を使います（自動で入ります）。



    
  
  • 初期値は <script type="text/markdown"> に書きます。HTML の中で字下げして書けるよう、共通の字下げは取り除きます。value プロパティ・value 属性でも渡せます（プロパティは 1 文字も変えずに読み込みます）。
    • 
  
  • 値は editor.value（Markdown）。変更のたびに input イベントが発生し、name を付ければフォームでそのまま送信できます。
    • 



Lit のコンポーネントから使う



ビルドなし（import map）で使う



markdown-it は、依存パッケージを含んだ 1 ファイル版（dist/browser/markdown-it.esm.min.mjs）を指定します。



原文の保持のしくみ


読み込むときに Markdown をトップレベルのブロック（見出し・段落・リスト・表・コード・引用・HTML ブロックなど）に分け、それぞれの原文を覚えておきます。書き出すときは次のように組み立てます。



  
ブロックの状態書き出し

  
中身も属性も変わっていない原文そのまま（前後の空行や参照定義 [名前]: URL も原文のまま）

  
中を編集したそのブロックだけ Markdown に書き直す（リストは元の記号を使う）

  
新しく足したMarkdown に書き出す（文書で多く使われている記号・フェンスに合わせる）

  
削除した書き出さない（前にあった参照定義は残す）




元に戻すで編集前の状態に戻れば、書き出しも原文に戻ります。常に全体を書き直したい場合は preserve-source="false" にします。

設定と API


<formulit-editor> の属性・プロパティ・メソッド・イベントはすべて使えます（API リファレンス）。追加・変更点は次のとおりです。



  
名前説明

  
valueMarkdown（GFM）の文字列

  
toolbar省略時は MARKDOWN_TOOLBAR（Markdown で表せる機能だけ）。fontColor などを加えると、その書式は HTML で残る

  
preserve-source既定 true（触っていないブロックは原文のまま）。"false" で毎回全体を書き直す

  
markdownOptionsmarkdown-it のオプション（例: { linkify: false }）

  
plain 属性本文の既定の見た目（引用の線・コードの背景・表の罫線など）を付けない

  
getSelectionMarkdown()選択範囲の Markdown





  
export説明

  
FormulitMarkdown要素のクラス（FormulitEditor を継承）

  
MARKDOWN_TOOLBAR既定のツールバー

  
markdownToHTML(md) / htmlToMarkdown(html)変換

  
createMarkdownIt(options)formulit-markdown と同じ設定の markdown-it

  
parseBlocks(md)ブロックごとの HTML と原文

  
nodesToMarkdown(nodes, style) / detectStyle(md)DOM ノードの書き出し / 原文の書き方（記号）の推定
