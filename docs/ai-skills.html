AI 用スキル

formulit を組み込む・設定する・プラグインで拡張するコードを、Claude などの AI に正しく書かせるためのスキルを同梱しています。

スキルとは

Agent Skills の形式（SKILL.md と参考資料）で書かれた、AI 向けの手引きです。AI は formulit に関する作業のときだけ読み込み、必要に応じて詳しい資料を参照します。

次のような、よくある間違いを防ぎます。

  • editable.innerHTML を直接書き換えて、履歴や原文保持を壊す
  • 独自プラグインで transact を使わず、元に戻せない変更をする
  • ツールバーのグループを属性に書こうとする、プラグインの登録が遅くて init が動かない
  • 初期値を <template> で渡して「原文そのまま」を期待する

構成

ファイル内容
SKILL.md概要・最小の使い方・必ず守ること・よくある間違い
references/api.md属性・プロパティ・メソッド・イベント・CSS 変数・export
references/toolbar.mdツールバー項目名とグループ
references/plugins.md独自プラグインの作り方
references/recipes.md実装例（Lit・フォーム・アップロード・自動保存・CDN など）

references/markdown.mdMarkdown 版（<formulit-markdown>）の使い方と注意

スキルをダウンロード（zip）

Claude Code で使う

formulit を使うプロジェクトの .claude/skills/ にフォルダごとコピーします。npm でインストールしていれば node_modules/@hidemikimura/formulit/skills/ に入っています。

以後、formulit に関する依頼（「記事の編集画面に formulit を組み込んで」「画像を S3 にアップロードするようにして」「独自のボタンを追加して」など）で自動的に使われます。

Claude（claude.ai・デスクトップアプリ）で使う

  1. 上のボタンから formulit-skill.zip をダウンロードします。
  2. Claude の設定の「スキル」から zip をアップロードします。

依頼の例

  • 「Lit の記事編集フォームに formulit を入れて、本文を body として送信できるようにして」
  • 「ツールバーを『履歴』『装飾』『挿入』のグループにまとめて」
  • 「画像を /api/images にアップロードし、失敗したらトーストで知らせて」
  • 「選択した文字を <span class="ruby"> で囲むボタンをプラグインで追加して」
  • 「入力が 3 秒止まったら下書きを保存して、保存状態を表示して」

ライブラリの API を変更したときは、skills/formulit/ も合わせて更新してください。npm run docs:build でこのサイトの閲覧用コピーと zip も更新されます。
