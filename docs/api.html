メソッド

利用側でよく使うもの

メソッド説明
getHTML() / setHTML(html)value と同じ
focusEditor()編集領域にフォーカス（最後の選択位置を復元）
undo() / redo()元に戻す / やり直し
toggleSource(force?) / toggleFullscreen(force?)ソース表示 / 全画面の切り替え
insertHTML(html)カーソル位置に HTML を挿入（サニタイズされる）
saveNow()自動保存を今すぐ実行
getStats(){ chars, charsNoSpace, words }
insertVariable(valueOrVariable)カーソル位置に変数を挿入（'sku' または { label, value }）
openDropdownItem(name)ドロップダウン項目を開く（グループ内ならグループごと）

プラグイン作成用

メソッド説明

defaultToolbar（getter）toolbar 未設定時のツールバー。継承した要素で差し替える（formulit-markdown が使用）

イベント

すべてホスト要素（<formulit-editor>）から発生し、bubbles・composed です。

イベントタイミングdetail
input内容が変わるたび—
changeフォーカスが外れたとき（変更があれば）—
formulit-modeソース表示の切り替え{ mode }
formulit-fullscreen全画面の切り替え{ fullscreen }
formulit-upload / formulit-upload-error画像アップロードの完了 / 失敗{ file, url } / { file, error }
formulit-autosave / formulit-autosave-error自動保存の成功 / 失敗{ value } / { error }
formulit-variable-insert変数を挿入したとき{ variable, text }
formulit-selectionchange選択の変更（連続入力中は間引く）—

名前説明
