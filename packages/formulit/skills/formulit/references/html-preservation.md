# HTML 保持の仕組みとトラブルシューティング

## 保証されること

1. **未編集なら原文そのまま**: `value` を設定して何も編集していなければ、`value` は 1 文字も変えずに同じ文字列を返す（引用符・大文字・空白・`<br/>`・`&copy;` などの書き方まで）。ソース表示で編集した HTML も同様。
2. **編集後も未変更部分は原文そのまま（部分的な原文保持）**: 読み込み時に「原文のどの範囲がどのノードになったか」を記録し、MutationObserver で変更を追跡する。
   - 変更なしのノード → 原文の文字列
   - 中身だけ変わった要素 → 原文の開始タグ・終了タグ + 中身を同じ規則で処理
   - 属性が変わった要素・新しい要素 → ブラウザのシリアライズ
3. **出力は常に編集結果と一致**: つなぎ目で意味が変わるおそれがあるとき（終了タグを省略した `<p>x` の直後に別の内容が来た等）は、組み立てた HTML を再パースして DOM と等価か確かめ、等価でなければ文書全体をブラウザのシリアライズで返す。
4. **DOM にあるものは消さない**: class・style・data-*・独自要素・空要素（`<i class="icon"></i>`）・コメント・`details`・iframe・`<style>` など。エディタが編集用に付けた属性（`contenteditable` など）は出力時に元の値と並び順へ戻る。

## 出力が変わるケース（仕様）

| ケース | 理由 |
|---|---|
| 初期値を `<template>` や `value` 属性で渡すと、引用符・大文字・文字参照が整形される | ブラウザが先にパースするため。原文そのままにするなら `value` プロパティか `<script type="text/html">` |
| `<script>`・`on*` 属性・`javascript:` URL が消える | `sanitize="strip"`（既定）。残すなら `sanitize="none"` |
| 除去が起きた文書は未編集でも `dirty` が `true` | 危険な記述を「原文そのまま」で素通しさせないため |
| `<p>` の中の `<div>` など、不正な入れ子が直る | ブラウザのパーサーが読み込み時に直す（どのエディタでも同じ） |
| 属性を変えた要素は `"` 囲みなどブラウザの書き方になる | その要素だけ作り直すため |
| 末尾に画像・表などを挿入すると後ろに `<p><br></p>` が入る | 続けて入力できるようにするため |
| 箇条書き化・見出し化した段落 | 要素自体が変わるため作り直し |
| 貼り付けた HTML の `style` が消える（Chrome/Safari からのコピー） | コピー時にブラウザが計算済みスタイルを書き込むため除去。手書き HTML はソース表示に貼る |
| アップロード中の画像の `src` が `blob:` | 完了後に差し替わる |

## 読み込み直すと失われるもの

- HTML 埋め込み（`htmlEmbed`）で挿入した要素の保護（クリックで選択・ダブルクリックで編集）は挿入時だけ。読み込み直した後も保護したい要素には `data-protect` を付けるか、`protect` 属性のセレクタに含める。

## トラブルシューティング

- **「未編集なのに原文と違う」** → 何か除去されていないか（script / on* / javascript:）。`sanitize="none"` で比較する。
- **「保存した HTML にエディタ用の属性が混ざる」** → `value` ではなく `editable.innerHTML` を読んでいないか確認。`value` からは `data-formulit-*`・一時的な `contenteditable` は除かれる。
- **「独自プラグインで変えた部分が保存されない／元に戻せない」** → `transact` の外で DOM を変えている。
- **「入力が重い」** → `input` のたびに `value` を読んで大きな DOM に描画していないか。150ms 程度間引く。エディタ側の処理は 300 段落の文書で 1 文字あたり約 1ms。
- **「本文にサイトの CSS が効いてしまう／効かない」** → 編集領域はライト DOM。`formulit-editor .formulit-editable …` のセレクタで調整する。
- **比較したいとき** → `import { serialize } from '@hidemikimura/formulit'` の `serialize(ed.editable)` がブラウザ標準のシリアライズ（原文保持なし）。`preserve-source="false"` でも同じ出力になる。
