実際の組み込みでよく使う実装例です。

画像をサーバーへアップロードする

imageUploader に「ファイルを受け取って URL を返す関数」を設定すると、画像ボタンのファイル選択・ドラッグ＆ドロップ・スクリーンショットの貼り付けのすべてで使われます。失敗（例外）すると挿入した画像は取り除かれ、formulit-upload-error が発生します。

ライブデモ画像ファイルをドロップ／貼り付け／画像ボタンから選ぶと、1 秒かけて「アップロード」します（この例ではファイル名を URL にするだけ）

  





アップロード中の value には一時的なプレビュー用 URL（blob:）が入り、完了後に差し替わります。未設定のときは data URL（Base64）で埋め込みます。



自動保存



状態（未保存の変更あり・保存中・保存しました・失敗）はステータスバーに表示され、未保存のままページを離れようとすると確認が出ます。Ctrl/⌘+S か ed.saveNow() ですぐ保存します。



文字数制限のあるフォーム



max-chars は表示のみ（超えると赤字）です。送信を止めるなら自分で判定します。




読み取り専用のプレビュー



表示するだけなら、保存した HTML をそのままページに出す方が軽量です（エディタ固有のマークアップは出力に含まれません）。



サイト独自のクラスを選べるようにする



クラスの見た目はページ側の CSS で定義します。エディタの中にも同じ CSS が効くので、編集中から実際の見た目で確認できます。



画像の配置をクラスで出力する



既定は style="float: left; …" なので、表示側に CSS がなくても配置されます。



script を含む HTML をそのまま扱う



script・on* 属性・javascript: URL を出力に残します（編集中は実行されないよう無効化）。信頼できる利用者だけが使う管理画面などで使い、表示側で XSS 対策を行ってください。



特定の要素を編集させない



一致する要素は編集中だけ contenteditable=false（丸ごと選択・削除のみ）になります。出力には付きません。



メールテンプレートに差し込み変数を入れる


変数の一覧をサーバーから受け取り、Lit のテンプレートで渡す例です。保存される HTML には {{ customer_name }} のような文字列がそのまま入るので、送信時にサーバー側のテンプレートエンジンで置き換えます。



Handlebars 形式以外（${name} や %name%）を使うときは variableFormat を設定します（詳細）。



1 ページに複数のエディタ


いくつ置いても構いません（履歴・検索・設定はエディタごと）。プラグインの登録は全エディタ共通なので、エディタごとに機能を変えるなら plugins / toolbar をそれぞれ設定します。
